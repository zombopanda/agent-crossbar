# Agent Crossbar v0.3.5

Tmux provider jobs now have a race-safe stop lifecycle.

## Fixed

- A `job_stop` issued during tmux startup can no longer leave an orphaned
  session behind.
- Stopped jobs remain terminal even if a provider completes concurrently; a
  stale provider result can no longer surface as success from `job_result`.
- Tmux monitors stop promptly when a job is cancelled.

## Verified

- Live Reasonix/DeepSeek Pro tmux E2E verifies incremental `job_tail`, normal
  stop, and immediate-stop startup races.
