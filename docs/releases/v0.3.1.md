# Agent Crossbar v0.3.1

Claude model discovery now exposes the versioned model IDs accepted by Claude
Code instead of mutable family aliases.

## Fixed

- `profiles_list` discovers the live Claude `/model` picker and publishes IDs
  such as `claude-opus-5` and `claude-sonnet-5`.
- New model versions and families are normalized from the picker at discovery
  time, so a Crossbar release is not needed for a Claude model rollout.
- Claude launches and validation require the discovered full ID; aliases such
  as `opus` and `sonnet` are rejected.

See the [README](../../README.md) for installation and the full contract.
