# Agent Crossbar v0.3.8

## Fixed

- Prevented premature completion when a provider is quiet but still running:
  state-aware waiting, independent ACP heartbeats, and per-job event sequencing
  locks keep silence and workspace-diff absence from being mistaken for a stall.
- OpenCode `dev` ACP sessions now select the provider-advertised `build` mode;
  whitespace-only or empty dev output fails closed with `acp_empty_result`.

## Changed

- The public 8-tool MCP surface and provider-neutral `agent_start` contract are
  unchanged.
- Release work consolidates commits `ac70226`, `cadf227`, and `b9adf61`.

  router → Agents MCP → OpenCode, with native OpenCode session `agent=build`
  and 7 generated-task pytest checks passing.
