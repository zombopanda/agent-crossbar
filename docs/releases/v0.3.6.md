# Agent Crossbar v0.3.6

README refreshed with registry badges; stopped-job result envelope now surfaces correctly.

- `job_result` for stopped ACP jobs now reads the persisted envelope
  (`status`, `stop_reason`, `technical`, `failure`, `resolved`) instead
  of returning a bare `"stopped"` — client-side result parsing no longer
  diverges between stop paths.

## Changed

- README: added npm + PyPI version badges, bumped version references from
  v0.2.0 to v0.3, and removed the Demo section (links remain in the repo
  under `demo/`).
