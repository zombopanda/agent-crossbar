# Agent Crossbar v0.3.3

Claude background sessions can now accept safe interactive follow-ups without
switching to Claude print/SDK mode.

## Added

- `agent_start(profile="claude", interactive=true)` starts native
  `claude --bg` and attaches a harness-owned tmux terminal to that same session.
- `job_send` delivers the next user turn to the attached native Claude session,
  and `job_tail` exposes its live terminal output.

## Fixed

- Claude provider log deltas correctly handle sliding log tails.
- Idle Claude sessions with a complete answer finalize reliably.
- Job ownership is checked before any Claude or tmux stop operation; a foreign
  client cannot cancel another session's job.
- An attach whose tmux output cannot be piped fails cleanly and removes its
  orphaned terminal session.

`claude -p` remains disabled, so these follow-ups continue to use the ordinary
Claude subscription path.
