# Agent Crossbar v0.3.7

## Fixed

- ACP-backed Codex and OpenCode jobs now forward every assistant
  `AgentMessageChunk` to `job_tail` as `log_delta`. Tails therefore stream
  response text while the job is running instead of remaining silent until the
  terminal result.
- The maintainer-only provider gate re-reads the final tail and requires the
  ACP lifecycle `acp_command` → `log_delta` → `acp_completed`, so a dropped
  stream is a live-gate failure.
- Codex now validates selected models against the same live catalog exposed by
  `profiles_list`, preventing advertised models from failing pre-launch.

## Changed

- Full provider-surface mode now checks discovery, readiness, job visibility,
  every claimed ask/review/dev task, and claimed interactive send/stop support.
- The gate recognizes current Claude and Reasonix terminal transcript shapes
  without treating a prompt echo as an answer.
- ChatGPT Pro browser turns now have verified lifecycle, cancellation,
  isolation, bounded context, and redacted diagnostic handling. Public MCP
  contracts remain unchanged.
- Internal editor, assistant, and OpenSpec working files are excluded from
  source distributions.

## Verification

- Credential-free CI-equivalent tests, lint/format checks, package build,
  archive audits, and install smoke were run for this release.
- The authenticated ChatGPT Pro browser live gate was explicitly skipped for
  this release at maintainer direction. Provider gates remain manual workflows
  and are never run by public CI.
