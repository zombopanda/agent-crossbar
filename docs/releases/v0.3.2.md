# Agent Crossbar v0.3.2

The public command-line entrypoint now has standard self-describing commands.

## Fixed

- `uvx agent-crossbar --help` prints usage and available commands without
  starting the MCP server.
- `uvx agent-crossbar --version` prints the installed package version.
- `agent-crossbar doctor --help` now uses the same standard command parser.

See the [README](../../README.md) for installation and the full contract.
